# Experiments

| 编号 | 实验名称 | 描述 |
|---|---|---|
| 01 | UIA 原型 | 只用 UIA 能否读到 Windows Terminal 的窗口、标签页与全文，并判断 Claude Code 的状态 |
| 02 | 滚动模型 | 页面高度等于内容总高（保留原生滚动条）时，能否不停在「半段 + 半段」 |

## 01-uia-prototype

- **状态**：通过（6 项验收全绿）
- **形式**：prototype（PowerShell 脚本 + C# 控制台轮询）
- **验收**：人工
- **结论**：UIA 可行，不需要 ConPTY、剪贴板或 OCR
- **skip 项**：无
- **局限**：只在 Windows Terminal 上验过，样本单机 13 个窗口
- **遗漏**：跨权限边界（更高完整性级别的进程）未验
- **疑虑点**：状态靠末行字符判断，改版即失效

## 02-scroll-model

- **状态**：通过（9 项验收全绿，跨段停点偏差 0）
- **形式**：prototype（实验页 + CDP 探针，产出 `reading-motion.ts`）
- **验收**：自动（`verify-*` 与等价回归自跑）
- **结论**：采用 v=2（页面高 = 内容总高 + 每帧按方向复位）
- **skip 项**：无
- **局限**：浏览器内验收，壳内 WebView 未验；输入只覆盖滚轮与触控板
- **遗漏**：长文档的每帧开销未测
- **疑虑点**：吸附逐帧判定，低刷新率或后台标签页可能漏帧
