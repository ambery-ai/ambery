# Capability Evaluation Project

[English](capability-evaluation-project.md) | 中文

## 原则

> **项目目的与边界**——本项目将 Agent Assistance 的目的性能力拆分为可泛化的细分能力与任务，逐步建立可重复的评估、回归、覆盖与演进体系；不定义 agent 的最终能力目标（见 `docs/agent-assistance.md`），也不定义 Case Runner 的格式和执行机制（见 `docs/case-runner.md`）。

> **本文档范围**——本文定义能力计划、泛化任务、评估项目、覆盖和演进；Case Runner 只是其中一种评估载体。
