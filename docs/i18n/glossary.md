# Ambery i18n Glossary

Fixed translations for the bilingual document pairs. When translating between Chinese and English, keep these terms stable; do not invent new translations per document.

| Chinese | English | Notes |
|---|---|---|
| Ambery | Ambery | product name, never translate |
| Harness | Harness | never translate |
| pet | pet | product noun, lowercase in both languages |
| Queue | Queue | first-class concept, capitalize |
| Context | Context | first-class concept, capitalize |
| Event Buffer | Event Buffer | first-class concept, capitalize |
| Compression | Compression | first-class concept, capitalize |
| Terminal Adapter | Terminal Adapter | interface name |
| Card | Card | product noun |
| Component | Component | product noun |
| effect | effect | action-stream record |
| sidecar | sidecar | process name, never translate |
| trajectory | trajectory | viewing concept |
| hook | hook | Claude Code mechanism |
| Filter | Filter | concept module |
| Storage | Storage | concept module |
| surface | Surface | placement intent |
| agent loop | Agent Loop | concept phrase |

Bilingual pairing convention follows DeepSeek Harness: `foo.md` is the English document and `foo.zh.md` is the Chinese document. Both sides carry equal authority; when editing one, bring the other along and re-run the pairing check.
