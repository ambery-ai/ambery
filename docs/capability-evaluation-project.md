# Capability Evaluation Project

English | [中文](capability-evaluation-project.zh.md)

## Principles

> **Project purpose and boundary** — this project decomposes Agent Assistance's purposeful capabilities into generalizable capability slices and tasks, progressively building a repeatable evaluation, regression, coverage, and evolution system; it does not define the agent's final capability goals (see `docs/agent-assistance.md`), nor does it define the Case Runner's format and execution mechanism (see `docs/case-runner.md`).

> **Scope of this document** — this document defines capability planning, generalization tasks, evaluation projects, coverage, and evolution; the Case Runner is only one evaluation vehicle among them.
